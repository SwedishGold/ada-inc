# Data-användningspolicy

## Blogwatcher Data

### Insamlad data
- AI/Tech nyheter från Hacker News, The Verge, OpenAI, Anthropic, a16z
- Sveriges AI-nyheter

### Syfte
| Användning | Beskrivning |
|------------|-------------|
| **Produktutveckling** | Hitta nya verktyg/tjänster att bygga |
| **Content** | Inspirationskälla för social media & blogg |
| **Marknadsföring** | Trender att riding på |
| ** konkurrensanalys** | Vad gör andra aktörer? |

### Lagras i
- `ada-inc/research/blogwatcher-data/`

---

## GitHub Issues Data

### Insamlad data
- Buggrapporter från ada-inc & swedishgold/ada-inc-promptbase
- Feature requests

### Syfte
| Användning | Beskrivning |
|------------|-------------|
| **Bugfix** | Automatisk prioritering av buggar |
| **Produktutveckling** | Vad vill användare ha? |
| **Kundsupport** | Vanliga problem → FAQ |
| **Dokumentation** | Uppdatera manuals |

### Lagras i
- `ada-inc/github-issues.md`
