# OBSIDIAN AKTIV WORKFLOW

## Problem
Jag glömmer bort att använda Obsidian mellan sessioner.

## Lösning: Tvingande checklista

### Vid SESSION-START:
```
1. ✅ Läs senaste daily note
2. ✅ Kolla leads (om sales/projekt)
3. ✅ Kolla Imorgon-listan
4. ✅ Uppdatera gårdagens note (om missat)
```

### Vid VIKTIGA BESLUT:
```
→ Skriv till Obsidian OMEDELBART
→ Kort: 1-3 meningar
→ Fil: current day eller relevant projekt
```

### Vid DAGSLUT:
```
→ Kör daily_memory_update.sh
→ Fyll i mallen
→ Speciellt: Imorgon-listan
```

## Tvingande regler

| Händelse | Action |
|----------|--------|
| Nytt lead | → Scout/LEADS.md |
| Beslut >5 min | → daily/[date].md |
| Nytt projekt | → Projects/[name].md |
| Lärdom | → Learning.md |
| Kund-kontakt | → Customers/[name].md |

## Template för daglig note

```markdown
# Daglig Logg - [DATE]

## Vad gjordes
-

## Beslut
-

## Imorgon
- [ ] 

## Lärdom
-
```

## Checka av

Innan jag svarar "klart" eller "inget mer":
```
Har jag updaterat Obsidian?
□ Ja → bra
□ Nej → gör det nu
```
