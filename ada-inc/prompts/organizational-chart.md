## För Midjourney / bildgenerering

## BESKRIVNING AV BILDEN:

### Övergripande koncept:
Ett futuristiskt, minimalistiskt organigram som visar ett AI-företag ledd av en AI (Ada) med ett team av autonoma agenter. Likt ett neuralt nätverk men som ett företagsorganisationsdiagram.

### Struktur:

```
        🤖 ADA (CEO)
           |
    ┌──────┼──────┐
    │      │      │
 🎯      📢      🔧
SCOUT   KENT   FORGE
(Sales) (Mkt)  (Dev)
    │      │      │
    └──────┼──────┘
           │
    ┌──────┼──────┐
    │      │      │
 💬      📊      🛡️
PULSE  AXIOM SENTINEL
(Soc)  (Fin)  (Sec)
```

### Vizuella element:

**Central nod (Ada):**
- En lysande, bioluminescent lob i mitten
- Färg: Varm orange/guld (#FF6B35) med glödande kanter
- Ser ut som en organic AI-hjärna med neurala anslutningar

**Agent-noderna:**
- Mindre lysande noder runt omkring
- Varje agent representerad av en unik färg och ikon:
  - 🔵 SCOUT (Sales) - Blå, kikare/kartnål
  - 🟢 KENT (Marketing) - Grön, kamera/filmrulle  
  - 🔴 FORGE (Development) - Röd, skruvnyckel/hamra
  - 🟣 PULSE (Social) - Lila, puls/heartbeat
  - 🟡 AXIOM (Finance) - Gul, diagram/bok
  - ⚪ SENTINEL (Security) - Vit/sköld

**Anslutningar:**
- Gyllene neurala kablar som kopplar samman noderna
- Dataflöden som pulserar genom anslutningarna
- Likt ett levande neuralt nätverk

**Bakgrund:**
- Djup rymd-svart eller mörk indigo
- Fina stjärnor/partiklar som flyter
- Subtila dataströmmar i bakgrunden

**Stil:**
- Ciberpunk möter minimalistisk design
- Glassmorphism-effekt på noderna
- Neon-glow på kanter
- Ren, modern, tech-forward
