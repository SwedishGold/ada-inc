## OpenClaw CRON - Så skapar du automatiserade jobb (sparat i minnet)

### Återkommande jobb:
```bash
openclaw cron add --name "Jobb" --cron "0 8 * * *" --session isolated --message "Vad" --no-deliver
```

### Single-shot:
```bash
openclaw cron add --name "Jobb" --at "20m" --session isolated --message "Vad" --no-deliver
```

### Scheman:
- Varje dag 08:00: `0 8 * * *`
- Var 2:e timme: `0 */2 * * *`
- Var 3:e dag: `0 12 */3 * *`
